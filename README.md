# LIBFT_QUEST

Juego de terminal retro para repasar la **libft** de 42. Cincuenta y siete retos repartidos en seis sectores, de menor a mayor dificultad, para consolidar tanto cada función como las relaciones entre ellas.

Hecho por **coscosgram**.

## Cómo se juega

- Seis sectores: caracteres, memoria, cadenas, heap, fd y listas.
- Cinco tipos de reto: elegir una respuesta, marcar varias, completar código, encontrar la línea con el error y ordenar piezas para construir una función entera.
- Tres vidas por intento de sector. Un fallo cuesta una vida y la pregunta vuelve más tarde.
- Un sector se abre al completar el anterior. Los superados se pueden repasar sin límite de vidas.
- El inventario muestra las funciones dominadas y de cuáles depende cada una.
- Español e inglés: el botón ES / EN de la barra superior cambia el idioma al instante y se recuerda.
- Música chiptune original, generada en el propio navegador. Se activa con el botón ♪ MÚSICA de la barra superior.
- Efectos de sonido 8 bits en botones, aciertos, fallos y fin de sector (botón ◆ SONIDOS para silenciarlos).
- Teclado: números para elegir, Enter para comprobar, P para la pista.

## Cómo usarlo

Es un único archivo, `index.html`, sin dependencias ni proceso de compilación. Ábrelo en el navegador o publícalo con GitHub Pages.

El progreso se guarda en el almacenamiento local de tu navegador, así que cada persona conserva el suyo en su equipo.

## Nota

Proyecto no oficial de repaso, sin relación con la Escuela 42. Las preguntas son originales.

# LIBFT_QUEST (English)

A retro terminal game to review 42's **libft**. Fifty-seven challenges across six sectors, from easiest to hardest, to consolidate both each function and the relationships between them.

Made by **coscosgram**.

## How to play

- Six sectors: characters, memory, strings, heap, fd and lists.
- Five challenge types: pick an answer, select all that apply, complete the code, find the buggy line, and order code pieces to build a whole function.
- Three lives per sector attempt. A mistake costs one life and the question comes back later.
- A sector unlocks once the previous one is cleared. Cleared sectors can be reviewed without any life limit.
- The inventory shows the functions you have mastered and which ones each depends on.
- Spanish and English: the ES / EN button in the top bar switches language instantly and is remembered.
- Original chiptune music, generated in the browser itself. Turn it on with the ♪ MUSIC button in the top bar.
- 8-bit sound effects on buttons, correct and wrong answers and sector clears (the ◆ SOUNDS button mutes them).
- Keyboard: number keys to choose, Enter to check, P for the hint.

## How to use it

It is a single file, `index.html`, with no dependencies and no build step. Open it in a browser or publish it with GitHub Pages.

Progress is saved in your browser's local storage, so everyone keeps their own on their own device.

Unofficial review project, not affiliated with 42 School. The questions are original.
