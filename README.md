# LIBFT_QUEST

Juego de terminal retro para repasar la **libft** de 42. Cincuenta y un retos repartidos en seis sectores, de menor a mayor dificultad, para consolidar tanto cada función como las relaciones entre ellas.

Hecho por **coscosgram**.

## Cómo se juega

- Seis sectores: caracteres, memoria, cadenas, heap, fd y listas.
- Cuatro tipos de reto: elegir una respuesta, marcar varias, completar código y encontrar la línea con el error.
- Tres vidas por intento de sector. Un fallo cuesta una vida y la pregunta vuelve más tarde.
- Un sector se abre al completar el anterior. Los superados se pueden repasar sin límite de vidas.
- El inventario muestra las funciones dominadas y de cuáles depende cada una.
- Música chiptune original, generada en el propio navegador. Se activa con el botón ♪ MÚSICA de la barra superior.
- Efectos de sonido 8 bits en botones, aciertos, fallos y fin de sector (botón ◆ SONIDOS para silenciarlos).
- Teclado: números para elegir, Enter para comprobar, P para la pista.

## Cómo usarlo

Es un único archivo, `index.html`, sin dependencias ni proceso de compilación. Ábrelo en el navegador o publícalo con GitHub Pages.

El progreso se guarda en el almacenamiento local de tu navegador, así que cada persona conserva el suyo en su equipo.

## Nota

Proyecto no oficial de repaso, sin relación con la Escuela 42. Las preguntas son originales.
